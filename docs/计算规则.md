# 计算规则

实现在 `macos/Sources/PayCore.swift`，测试在 `macos/Tests/main.swift`。移植到别的平台时，按这份规则写，再把测试用例原样搬过去跑一遍。

## 设置

| 字段 | 含义 | 默认 |
|---|---|---|
| `salaryType` | `monthly` 月薪 / `daily` 日薪 / `hourly` 时薪 | monthly |
| `salary` | 金额，必须 > 0 | 0（未设置） |
| `dayMode` | 月薪折算日薪按几天：`actual` 本期实际工作日（见「本期」）/ `standard` 21.75 天 / `custom` 自定义 | actual |
| `customDays` | 自定义天数，1–31 | 22 |
| `start` `end` | 上下班时间，零点起的分钟数；`end` 必须晚于 `start` | 540 / 1080 |
| `lunchEnabled` | 午休不计薪 | true |
| `lunchStart` `lunchEnd` | 午休时间，必须落在上下班之间 | 720 / 780 |
| `workdays` | 上班的星期，0 = 周日 … 6 = 周六 | [1,2,3,4,5] |
| `payday` | 每月几号发薪，决定「本期」从哪天算起；0 = 不设，按自然月 | 0 |
| `currency` | `¥` `$` `€` `£` 之一 | ¥ |
| `decimals` | 小数位，2–6 | 4 |
| `menuBar` | 菜单栏显示 `today` / `month`（本期已赚）/ `countdown` / `off` | today |
| `sound` | 进账时播放金币音 | false |
| `wishlist` | `[{name, price}]`，名称去空格后不能为空、价格 > 0 | 9 项默认 |

读进来的 JSON 缺字段就用默认值；越界的值拉回范围；重复的星期去重；空白的心愿项丢掉。

## 一天里的计薪时段

- 没有午休：`[start, end)` 一段。
- 有午休且合法：`[start, lunchStart)` 和 `[lunchEnd, end)` 两段（任一段长度为 0 就省略）。
- 每天计薪秒数 `paidPerDay` = 各段长度之和。

## 本期

- 没设发薪日：本期是自然月，`[本月 1 号, 下月 1 号)`，界面上叫「本月」。
- 设了发薪日 P：本期是 `[上一个发薪日, 下一个发薪日)`，含发薪日当天、不含下一个发薪日，界面上叫「本期」，工资条抬头写日期范围。某个月没有 P 号就按那个月的最后一天算。
- 例：P = 15，11/3 的本期是 10/15–11/14；11/15 当天开始新的一期 11/15–12/14。P = 31，11/3 的本期是 10/31–11/29（11 月按 30 号发）。

## 日薪与每秒工资

- 日薪：`daily` 直接用；`hourly` = 时薪 × paidPerDay / 3600；`monthly` = 月薪 ÷ 天数，天数按 `dayMode` 取本期工作日数、21.75 或自定义值。
- 每秒工资 `rate` = 日薪 ÷ paidPerDay。

按「实际工作日」折算时，本期最后一个工作日下班，本期已赚正好等于月薪。所以同样是月薪 8000，本期 22 个工作日时日薪约 363.64，21 个工作日时约 380.95。按天拿钱的应该直接选「日薪」，设置窗口会实时写出日薪是怎么算出来的。

## 状态

按顺序判断，命中第一条就停：

1. `setup`：没有计薪时段，或工资不大于 0
2. `off`：今天不在 `workdays` 里
3. `before`：还没到第一段开始
4. `after`：已经过了最后一段结束
5. `working`：落在某一段里
6. `lunch`：在两段之间

倒计时：`working` 到最后一段结束（墙上时间，含午休），`lunch` 到下一段开始，`before` 到第一段开始，其余为 0。`before` `after` `off` 再给出「下次上班」：今天、明天、周几或「几月几日」加上上班时间，最多往后找 14 天。

## 金额

- 今日已干 `worked` = 各段里已经过去的秒数之和。休息日为 0。
- 今日已赚 = worked × rate。午休时不涨，下班后等于日薪。
- 本期已赚 = 本期里今天之前的工作日数 × 日薪 + 今日已赚。
- 本期满勤 = 本期工作日数 × 日薪。
- 发薪日倒数：今天 ≤ 本月发薪日时，相差天数（当天为 0）；否则算到下个月的发薪日。

## 显示

- 金额先向下取整再格式化：`floor(v × 10^dec × (1 + 1e-12) + 1e-9) / 10^dec`，加千分位。这个容差是为了让 129.3 显示成 129.3000，而不是 129.2999。
- 倒计时向上取整到秒，格式 `h:mm:ss`。
- 工作时长：不到 1 分钟写「不到 1 分钟」；超过一天半的工时折成「N.N 个工作日」；其余写「X 小时 Y 分」。
- 心愿提示：按价格从低到高，找第一个比今日已赚贵的，所需工时 = (价格 − 已赚) ÷ rate。
- 已经赚到：找最贵的、不超过今日已赚的那一项，写成「N 杯奶茶」（名称以「一」开头时，把「一」换成数量）。

## 悬浮窗

- 大数字的整数位数按今天的日薪固定（休息日显示本期已赚，按本期满勤固定），涨的过程中宽度不变；还没走到的高位显示成暗色 0。
- 滚轮：最低位按 `value × 10^dec` 的小数部分连续转动，高位只在低一位从 9 转向 0 的那一段跟着进位。每秒转过 12 个数以上的位直接跳字；金额静止（不在上班中）时每一位都对齐到整数字。
- 金币面额：在 0.01、0.05、0.1、0.5、1、5、10、50、100、500 里，挑最小的、能让两枚金币之间至少隔 10 秒的那个。
- 摸鱼金额 = 摸鱼期间增加的计薪秒数 × rate，过了零点清零。
